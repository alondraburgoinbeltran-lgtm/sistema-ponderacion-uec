# Sistema de Ponderación de Cuentas Públicas · UEC

Aplicación web estática lista para GitHub Pages.

## Publicación
1. Sube todos los archivos y carpetas de este proyecto a la raíz del repositorio.
2. En GitHub: Settings → Pages → Deploy from a branch → `main` / root.
3. La app utiliza `localStorage` del navegador para guardar catálogos y ejercicios.

## Importante
- La lectura automática de PDF usa PDF.js desde CDN; si el PDF es escaneado sin texto, captura o pega los nombres manualmente en el modal de catálogo.
- Para uso institucional multiusuario o respaldo centralizado se recomienda posteriormente conectar una base de datos.
